# API-тесты Stellar Burgers

Автотесты API учебного сервиса Stellar Burgers.

## Проверки

- создание уникального пользователя;
- создание дублирующегося пользователя;
- создание пользователя без обязательных полей;
- логин существующего пользователя;
- логин с неверными учётными данными;
- создание заказа с авторизацией и без неё;
- создание заказа с ингредиентами, без ингредиентов и с неверным хешем.

## Запуск тестов

```bash
python -m pytest -v --alluredir=allure_results --clean-alluredir
```

## Allure-отчёт

```bash
allure serve allure_results
```
